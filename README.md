# Superstore Sales Dashboard

## Project Overview
An interactive Microsoft Excel dashboard built using the Superstore dataset to analyze sales performance and business trends.

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dashboard KPIs
- Total Sales: $1.92M
- Total Profit: $224.1K
- Profit Margin: 12%
- Total Orders: 1,952

## Key Insights
- Top 5 Profitable States
- Top 10 Profitable Cities
- Monthly Sales Trend
- Sales by Category
- Least Profitable Sub-Categories

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Dashboard Design
- Data Visualization
